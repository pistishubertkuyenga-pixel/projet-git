| Commande | Rôle |
|---|---|
| `pwd` | Afficher le dossier actuel. |
| `ls` | Lister les fichiers. |
| `cd` | Changer de dossier. |
| `mkdir` | Créer des dossiers. |
| `touch` | Créer des fichiers vides. |
| Commande | Rôle |
|---|---|
| `git clone` | Copier un dépôt. |
| `git switch` | Changer ou créer une branche. |
| `git add` | Préparer des modifications. |
| `git commit` | Les enregistrer dans l’historique local. |
| `git push` | Envoyer les commits au dépôt distant. |
